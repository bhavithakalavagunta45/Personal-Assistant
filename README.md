# Personal Assistant

A personal assistant web application built using Python and Flask.

## Features

- Entertainment
- Study tools
- Recipe manager
- Budgeting
- Calculator
- Other useful personal assistant features

## Technologies Used

- Python
- Flask
- HTML
- CSS

## How to Run

Install Flask:

```bash
pip3 install flask
```

Run the application:

```bash
python3 app.py
```

Then open the URL shown in the terminal in your web browser.
